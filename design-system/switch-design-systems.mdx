*Pick which design system Figr uses for your next message, without leaving your project.*

Many teams have more than one design system: one for the web app, one for mobile, one for marketing. You can switch between them in the same project, so Figr designs each screen in the right style.

<Steps>
  <Step title="Open the design system picker">
    In the chat box, click the design system chip to see all the design systems you can use.

    <Frame>
      <img
        alt="Design system picker open from the chip in the Figr chat box"
        title="Open the design system picker in Figr"
        src="/images/Screenshot-2026-10-21-at-1.58.47-PM.png"
      />
    </Frame>
  </Step>
  <Step title="Find the one you want">
    Search by name, or scroll the list. Your workspace default is marked so it's easy to spot.

    <Frame>
      <img
        alt="Searching the design system picker by name in Figr"
        title="Find a design system in the picker"
        src="/images/Screenshot-2026-10-21-at-2.00.09-PM.png"
      />
    </Frame>
  </Step>
  <Step title="Select it">
    Click a design system to make it active. It shows as a chip above your message. Hover the chip to see its full name.

    <Frame>
      <img
        alt="Selected design system shown as a chip above the message in the Figr chat box"
        title="Active design system chip in Figr"
        src="/images/Screenshot-2026-10-21-at-1.59.43-PM.png"
      />
    </Frame>
  </Step>
  <Step title="Send your message">
    Figr uses the selected design system for this message and the ones after it, until you switch again.
  </Step>
</Steps>

<Tip>
  Want the same screen in two styles? Ask Figr to design it once, switch design systems, then ask for the same screen again. You'll get both side by side on the canvas.
</Tip>

## Set a default for your workspace

Set a design system as your workspace default from its menu on the Design System page. New canvases preselect the default, so teammates start on-brand without picking it themselves.
