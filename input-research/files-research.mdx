Use files and research when your context lives outside the product screen: PRDs, specs, research notes, analytics exports, customer feedback and references.

## Add files

In the chat box, open **Add files and more**, or drag files in.

- Upload a PRD and ask Figr to find missing requirements
- Upload an analytics CSV and ask Figr to find UX opportunities
- Upload screenshots and ask Figr to audit the current flow
- Upload research notes and ask Figr to suggest directions

## Supported files and limits

| Type | Formats |
| --- | --- |
| Images | PNG, JPG, WebP, GIF, SVG |
| Video | MP4, MOV, MKV, WebM |
| Documents | PDF, Markdown (.md, .mdx), plain text |
| Data and code | CSV, JSON, CSS, HTML, Mermaid |

| Limit | Value |
| --- | --- |
| Per file | 100 MB |
| All files in one message | 100 MB |
| PDF pages read per message | 75 |
| PDF in a Context Pod | 50 MB |

<Warning>
  Word (.docx), Excel (.xlsx) and PowerPoint (.pptx) files aren't supported. Export them to PDF, or paste the text, before adding them.
</Warning>

## Message or canvas?

Files you attach in the chat box apply to that message only and don't land on the canvas. Add a file to the canvas when you want it visible next to the work, or to a [Context Pod](/product-intelligence/context-pods) to reuse it in every project.

## Paste a link

Paste a URL into your message and Figr reads the page. For pages behind a login, use [Figr Capture](/input-research/chrome-extension).

## Research before designing

Ask Figr to search the web and its design inspiration library when you want to study patterns before designing: compare competitors, understand common approaches, or ground a design in proven patterns.

```text
Research how top B2B SaaS tools handle team permissions, then suggest a better IA for our permissions page.
```

```text
Compare onboarding flows from similar products and suggest what we should learn before redesigning ours.
```

```text
Find common patterns for analytics dashboards and turn them into a design direction for our product.
```
