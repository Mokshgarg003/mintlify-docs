_Give Figr your PRDs, research and screenshots once, and use them in every project._

Files you add to a Context Pod become part of what Figr knows about your product. Every time you attach the pod, Figr uses them, so you don't have to upload the same PRD again in each chat.

<Steps>
  <Step title="Open your Context Pod">
    Go to **Product intelligence**, open a pod, switch to the **Sources** tab and click **Add a new source**.
  </Step>
  <Step title="Upload your files">
    Choose **Upload files** and add PDFs, Markdown or text files, screenshots, CSVs or HTML files. Images can be JPG, PNG, WebP or GIF.
  </Step>
  <Step title="Or paste text">
    Choose **Paste text** to add notes or requirements, and give them a title so they're easy to find later.
  </Step>
  <Step title="Check your sources">
    Each file shows its status in the **Sources** tab. Remove anything that's out of date.
  </Step>
</Steps>

<Info>
  **Pod or chat?** Files you attach in a chat apply to that message only. Files in a pod are used every time you attach the pod.
</Info>

## Supported files and limits

| Type | Formats |
| --- | --- |
| Images | PNG, JPG, WebP, GIF, SVG |
| Video | MP4, MOV, MKV, WebM |
| Documents | PDF, Markdown (.md, .mdx), plain text |
| Data and code | CSV, JSON, CSS, HTML, Mermaid |

Files can be up to 100 MB each. PDFs in a pod can be up to 50 MB.

<Warning>
  Word (.docx), Excel (.xlsx) and PowerPoint (.pptx) files aren't supported. Export them to PDF, or paste the text.
</Warning>

<Tip>
  Add a short instruction for words Figr gets wrong, like "We call customers 'members', never 'users'."
</Tip>
