_Give Figr your PRDs, research and screenshots once, and use them in every project._

Files you add to a Context Pod become part of what Figr knows about your product. Every time you attach the pod, Figr uses them, so you don't have to upload the same PRD again in each chat.

<Steps>
  <Step title="Open your Context Pod">
    Go to **Product intelligence**, open a pod, switch to the **Sources** tab and click **Add sources**.

    <Frame>
      <img
        alt="Add sources menu with Upload from computer selected"
        src="/images/docs/files-01-upload.png"
      />
    </Frame>
  </Step>
  <Step title="Upload your files">
    Choose **Upload from computer** and pick PDFs, Markdown or text files, screenshots, CSVs or HTML files. Images can be JPG, PNG, WebP or GIF. Files upload as soon as you select them.

    <Frame>
      <img
        alt="Uploaded files listed in the pod's sources"
        src="/images/docs/files-02-added.png"
      />
    </Frame>
  </Step>
  <Step title="Or paste text">
    Choose **Paste text** to add notes or requirements. In the **Create note** panel, give the note a title so it's easy to find later.

    <Frame>
      <img
        alt="Create note panel with a title and note content"
        src="/images/docs/files-03-text.png"
      />
    </Frame>
  </Step>
  <Step title="Check your sources">
    Every file is listed in the **Sources** tab with its type and size. Remove anything that's out of date.

    <Frame>
      <img
        alt="Sources tab listing every file in the pod"
        src="/images/docs/files-04-status.png"
      />
    </Frame>
  </Step>
</Steps>

<Info>
  **Pod or chat?** Files you attach in a chat apply to that message only. Files in a pod are used every time you attach the pod.
</Info>

## Supported files and limits

| Type | Formats |
| --- | --- |
| Images | PNG, JPG, WebP, GIF, SVG |
| Video | MP4, MOV, MKV, WebM |
| Documents | PDF, Markdown (.md, .mdx), plain text |
| Data and code | CSV, JSON, CSS, HTML, Mermaid |

Files can be up to 100 MB each. PDFs in a pod can be up to 50 MB.

<Warning>
  Word (.docx), Excel (.xlsx) and PowerPoint (.pptx) files aren't supported. Export them to PDF, or paste the text.
</Warning>

<Tip>
  Add a short instruction for words Figr gets wrong, like "We call customers 'members', never 'users'."
</Tip>
