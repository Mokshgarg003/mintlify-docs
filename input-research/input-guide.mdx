Pick inputs that match what you want Figr to understand. The closer the match, the less generic the output. Add any of them from **Add context** in the chat box.

| Goal | Use these inputs | Best for |
| --- | --- | --- |
| Understand an existing product | Screen recordings, Figr Capture, screenshots, Figma frames | Redesigns, UX audits, improving what exists |
| Follow your design system | A [Design System](/product-intelligence/design-system) from Figma, Storybook, npm or code | On-brand screens and Figma-ready output |
| Understand requirements | PRDs, PDFs, pasted text, product briefs | PRD-to-design, feature planning, requirements review |
| Reason from user behavior | Analytics CSVs, research notes, feedback, or a connected Mixpanel or Amplitude | Funnel fixes, activation flows, discovery |
| Use live team context | [Connectors](/product-intelligence/connectors) like Notion, Linear, Asana, Slack or GitHub | Designing from current specs, tickets and code |
| Study a live page or competitor | Figr Capture, a pasted URL, screenshots | Landing page analysis, competitor research |

<Tip>
  Inputs you add to a message apply to that message. To reuse them in every project, put them in a [Context Pod](/product-intelligence/context-pods).
</Tip>
