Pick the context that matches what you want Figr to understand. The closer the match, the less generic the output. Add any of it from **Add context** in the chat box, and it applies to that message.

| Goal | Add this in the chat | Best for |
| --- | --- | --- |
| Show how an existing flow works | A screen recording, Figr Capture, screenshots or Figma frames | Redesigns, UX audits, improving what exists |
| Follow your design system | Your [design system](/product-intelligence/design-system), picked from the chat box | On-brand screens and Figma-ready output |
| Work from requirements | PRDs, PDFs or pasted text | PRD-to-design, feature planning, requirements review |
| Reason from user behavior | Analytics CSVs, research notes, feedback, or a connected Mixpanel or Amplitude | Funnel fixes, activation flows, discovery |
| Use live team context | [Connectors](/product-intelligence/connectors) like Notion, Linear, Asana, Slack or GitHub | Designing from current specs, tickets and code |
| Study a live page or competitor | A pasted URL, Figr Capture or screenshots | Landing page analysis, competitor research |

<Tip>
  Want the same context in every project? Put it in a [Context Pod](/product-intelligence/context-pods) once and attach the pod instead.
</Tip>
