Every Figr project is one infinite canvas. Your chat on the side does the work; the canvas is where the results land, next to the context that shaped them.

## What lives on the canvas

| Item | What it is |
| --- | --- |
| Prototypes | Clickable, high-fidelity screens in your design system |
| Screens | A board of every route and state of a prototype, including loading, empty, error and success |
| Wireframes | Low-fidelity layouts you can edit part by part |
| Flows | User flow diagrams you can edit and export |
| Docs | PRDs, specs and other documents you can edit in place |
| Images, PDFs and videos | Screenshots, references and recordings you add |
| Links | Web pages, with a live preview |
| Sticky notes, comments and annotations | Your notes, which Figr reads on its next turn |
| Sections | Named groups that keep related work together |

## Chat and the canvas

- **Multiple chats.** Run separate conversations in one project, sharing the same canvas, files and history. Fork any finished turn to try another direction without changing the original.
- **Queued messages.** Send follow-ups while Figr works. They run in order when the current task finishes.
- **@ mentions.** Type `@` to reference a canvas item, a section, another chat or a file in your message.

## Working together

- **Live cursors.** See teammates' named cursors, and click an avatar to follow their view.
- **Comments.** Leave feedback on any item and @mention teammates. See [Organize the canvas](/canvas/organize).
- **History.** Every item keeps its own versions, and Activity can restore the whole canvas. See [History and layers](/canvas/history-layers).

## Moving around

Drag to pan, scroll to zoom, and hold Space to pan while a prototype is selected. Open **Help → Shortcuts** for the full list.
