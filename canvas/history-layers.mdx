_Undo a change that didn't work out, for one screen or the whole canvas._

Figr saves versions as you work, on two levels. Each artifact, like a screen, prototype or doc, has its own versions. The canvas also keeps a timeline of every change made across the project in **Activity**. Go back one artifact when a single change goes wrong, or go back the whole canvas when you want to return to an earlier point in the project.

## Go back one artifact

Use this when one screen, prototype or doc has gone in the wrong direction and the rest of the canvas is fine.

<Steps>
  <Step title="Open version history">
    Double-click a screen or prototype to open full screen, then open its version history.

    <Frame>
      <img
        alt="Version history open for a prototype in full screen in Figr"
        title="Open a prototype's version history"
        src="/images/Screenshot-2026-10-21-at-3.24.01-AM.png"
      />
    </Frame>
  </Step>
  <Step title="Browse earlier versions">
    Click through the list to preview each version.
  </Step>
  <Step title="Restore the one you want">
    Choose **Restore** on the version you want to go back to. It becomes the current version.

    <Frame>
      <img
        alt="Restore button on an earlier version of a prototype in Figr"
        title="Restore an earlier version of a screen"
        src="/images/Screenshot-2026-10-21-at-3.24.33-AM.png"
      />
    </Frame>
  </Step>
  <Step title="Keep going">
    Continue editing by hand or in chat. Later changes are saved as new versions, so you can always go back again.
  </Step>
</Steps>

## Go back the whole canvas

Use this when you want to return the whole project to an earlier point, for example before a round of changes across several screens.

<Steps>
  <Step title="Open Activity">
    Open **Activity** to see every change made in the project. Changes are grouped by day and by the prompt that made them.

    <Frame>
      <img
        alt="Activity panel showing canvas versions grouped by day and prompt"
        title="The Figr canvas Activity timeline"
        src="/images/Screenshot-2026-10-21-at-3.21.50-AM.png"
      />
    </Frame>
  </Step>
  <Step title="Find the point you want">
    Each entry shows what changed and when, so you can find the moment before things went wrong.
  </Step>
  <Step title="Restore it">
    Click **Restore this version**. The whole canvas returns to how it was at that point.

    <Frame>
      <img
        alt="Restore this version control on an earlier entry in the Activity panel"
        title="Restore the whole canvas from Activity"
        src="/images/docs/ver-03-restore.png"
      />
    </Frame>
  </Step>
</Steps>

<Tip>
  Not sure you want to lose the current version? [Duplicate the chat and canvas](/canvas/duplicate-fork) first, then restore in the copy.
</Tip>

## Find anything with Layers

Layers lists everything on the canvas: prototypes, notes, screenshots, flows and sections. Use it to find an item or move around a crowded canvas.
