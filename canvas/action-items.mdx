Select an item on the canvas and a toolbar appears above it. An item can be a prototype, wireframe, flow, doc, image, sticky note or any other artifact. The actions depend on the item type. This page covers prototypes, which have the most.

## The toolbar

| Action | What it does |
| --- | --- |
| Interact | Click through the prototype right on the canvas |
| Edit | Change text, colour, spacing and more without regenerating. See [Manual edit](/getting-started/tutorial/untitled-page-5) |
| Full screen | Open the prototype in a focused view |
| Context | Reference this item in your next message |
| Export | Open the Export menu (below) |
| More | Duplicate, Bring to front, Send to back, Hide, Delete |

## The Export menu

On a prototype, **Export** offers:

| Option | What it does |
| --- | --- |
| Export to Figma ▸ Export this screen | Send the current screen to Figma. See [Export to Figma](/export/figma) |
| Export to Figma ▸ Export all screens | Send every screen to Figma in one run |
| Copy this screen | Copy the current screen |
| Open in coding agent | Connect Claude Code, Cursor, VS Code or Codex. See [Figr MCP](/export/mcp) |
| Download code | Download the prototype's front-end code |

Other item types have their own options. Flow diagrams offer **Copy code** and **Download PNG**. Docs offer **Download PDF**, **Download Markdown** and **Copy as text**.

## In full screen

Full screen has more room and a few extra controls.

| Control | What it does |
| --- | --- |
| Interact / Edit / Comment tabs | Click through the prototype, edit it, or leave comments pinned to the screen |
| Prototype / Screens | Switch between the clickable prototype and a board of every screen and state |
| Code | Show the code behind the prototype |
| Theme | Preview in System, Light or Dark mode without changing your device theme |
| Version | Look back at any earlier version of this item |
| Device size | Check the prototype at different screen sizes |
