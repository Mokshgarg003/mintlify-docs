*Work on several ideas in parallel without starting a new project.*

Each chat is its own conversation with Figr, but everything it creates lands on the same canvas. Use separate chats to explore different directions, work on different parts of a feature, or let teammates work side by side in one project.

<Steps>
  <Step title="Start a new chat">
    Open a new chat from the chat panel. Your existing chats stay as they are.

    <Frame>
      <img
        alt="New chat button in the Figr chat panel"
        title="Start a new chat in a Figr project"
        src="/images/Screenshot-2026-10-21-at-3.43.55-PM.png"
      />
    </Frame>
  </Step>
  <Step title="Give it one job">
    Use each chat for a single task. For example, one chat for the onboarding flow and another for the settings page.
  </Step>
  <Step title="Switch between chats">
    Pick a chat from the list to pick up where you left off. Each chat remembers its own conversation.

    <Frame>
      <img
        alt="Chat list in a Figr project with one chat selected"
        title="Switch between chats in Figr"
        src="/images/Screenshot-2026-10-21-at-3.44.24-PM.png"
      />
    </Frame>

    <Tip>
      Name your chats by what they're for, like "Onboarding v2" or "Settings redesign", so you and your team can find the right one quickly.
    </Tip>
  </Step>
  <Step title="See everything on one canvas">
    Screens, flows and docs from every chat appear on the same canvas, so you can compare them side by side.
  </Step>
</Steps>

<Info>
  **Want to try a different direction?** [Duplicate the chat](/canvas/duplicate-fork) from any message. The original stays as it is, so you can explore without losing your work.
</Info>
