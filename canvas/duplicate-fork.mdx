*Branch off from any message to try a new direction.*

You can duplicate a conversation from any message in the chat. Figr gives you two options, depending on whether you want to keep working on the same canvas or explore on a separate copy. Your original chat and canvas stay as they are.

<Steps>
  <Step title="Pick the message to branch from">
    Find the message you want to start from and choose **Duplicate**.
  </Step>
  <Step title="Choose how to duplicate">
    Figr asks what you want to copy:

    - **Duplicate chat** starts a new chat from that message on the same canvas. Use it to try a different prompt or direction while everything you create still lands next to your existing work.
    - **Duplicate chat and canvas** creates a separate copy of both. Use it to explore bigger changes without affecting the original.
  </Step>
  <Step title="Continue in the new chat">
    Pick up from that message and ask Figr for the changes you want to try.
  </Step>
</Steps>

<Tip>
  Want to compare both directions side by side? Duplicate the chat. Expecting big changes you might throw away? Duplicate the chat and canvas.
</Tip>
