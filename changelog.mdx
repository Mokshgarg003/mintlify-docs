### **Version 3.8.0 - Aug 19, 2026**

**Features**

- **Wireframes on canvas.** Wireframes created in chat now appear as canvas nodes alongside prototypes and other project work.
  - Edit parts of a wireframe without generating the whole thing again.
  - Add wireframes from older chats back onto the canvas.
  - Resize, view fullscreen, copy as an image, use version history, and Select & Edit.
- **Multiple chats in one project.** Explore different directions without duplicating the whole project.
  - Switch between separate conversations while keeping the same canvas, files, and version history.
  - Fork any completed turn to try another direction without changing the original chat.
  - Each chat can generate independently.
- **Custom Skills.** Add standing instructions for how Figr should work with your team.
  - Keep a Skill always on or let Figr use it only when relevant.
  - Type `/` in chat to bring in a specific Skill.
  - Team members can view shared Skills, while owners and admins manage them.
- **In-app feedback.** Rate your experience directly from chat and add more context when something is not working.
  - Negative feedback can include reason tags and free text.
  - Responses save as you fill them in.
  - A book-a-call option appears when more help is useful.
- **Enterprise credit reshuffling.** Admins can move unused AI credits from one team seat to another.
  - Remaining credits now appear in Members & Seats.
  - Credit transfers stay within the same organization.
  - Enterprise shared-credit handling was also added to the project-sharing flow.

**Improvements**

- **More reliable usage tracking.** Settings → Activity now uses a real-time usage ledger instead of waiting on slower project scans.
  - A loading state appears while older organization history is indexed.
- **More reliable Design System indexing.**
  - Failed indexing jobs now retry instead of getting stuck.
  - Runs that index zero projects are no longer marked as complete.
- **More reliable code generation.** Subagents now run an automatic lint check while generating code.
  - Exploration and code tasks moved to a newer model.
  - Stability work reduced crashes and hangs introduced by the linting flow.
- **Better Figma export debugging.** Bulk Figma exports now record the same debugging information available for single-screen exports.

**Fixes**

- Fixed a typography-panel overlap issue.
- Fixed Figma frames attached through the plugin not appearing as visible attachment chips.
- Fixed Design System publishing failures caused by hardcoded package names in prototype imports.
- Fixed Design System republishing that could overwrite hand-written agent guidance.
- Fixed vendored Design Systems, including MUI-based systems, not rendering correctly in previews.
- Fixed several crashes and hangs in the code-generation flow.

### Version 3.7.0 - Aug 3, 2026

**Features**

- **Screens for prototypes.** View every route and UI state on one flow board. Loading, empty, error, and success states appear as separate frames with labelled sections and transition edges.
  - Export multiple screens to Figma in one run, with progress and errors shown per screen.
  - Use Generate screens to let the agent propose and build missing states.
- **Queued messages.** Send follow-ups while the agent works. Figr runs them in order once the current task finishes.
  - Edit, remove, or clear queued messages.
  - Queues pause after errors or when credits run out, and resume when ready.
  - Also works in Design System chats.
- **Organize canvas.** Group canvas nodes by creation date or type, including Prototypes, Documents, Flows, Images, and Stickies.
  - Manually created sections stay unchanged.
  - Sections now behave more like Figma frames.
  - Stickies, text, and documents now resize with live previews.
- **Context from past chats.** New chats can pull relevant decisions from earlier chats in the same Context Pod and show where they came from.
  - Screenshots and attachments help find the right past context.
  - Figr stays quiet when nothing relevant exists.
- **Comments on shared projects.** Signed-in viewers can comment and reply through public project links without joining the workspace. Only workspace members can resolve or delete threads.

**Improvements:**

- **Workspace join requests.** Users with a matching work email can find and request access to their team’s workspace.
  - Admins can approve requests from email or Settings → Members.
  - Workspaces can allow instant domain-based access or require approval.

- **More reliable Design Systems.**
  - Attached or switched Design Systems now apply to the next query.
  - Removing one clears it across the project and agent context.
  - Older Design Systems now open the upgrade flow instead of failing.
  - Newer projects now use the same token, component, and lint checks as older projects.

- **Faster canvas opening.**
  - Canvas content loads before full history and project files.
  - Duplicated prototypes reuse their existing previews.

- **Updated design agent.** The agent now uses Claude Opus 5, with Sonnet 5 for subagents. More steps now run in parallel.
  - The agent makes fewer repeated edit calls and unnecessary follow-up questions. Failed steps report clearly.
  - Video summaries use a newer, faster model.

- **Starter pricing.** The Starter plan is back to \$39 with 200 credits per month

**Fixes:**

- **Clearer Figma plugin errors.** The plugin now detects when Figma is in the background and asks you to bring it forward.
  - Design System scans explain why capture paused.
  - Chat responses stay active when Figma stops responding.
- Improved Mermaid diagram rendering, including fullscreen.
- Deleted projects now leave the sidebar immediately.
- Fixed several canvas, loading, and interaction issues.
