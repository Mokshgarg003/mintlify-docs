_Write product docs that already know your product._

<iframe src="https://www.youtube.com/embed/TeR251naXr4" title="Generate PRDs and product documentation with Figr AI" frameBorder="0" className="w-full aspect-video rounded-xl" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen />

Figr drafts PRDs, feature specs and other product docs from the context you give it. Because it works from your real product and inputs, the first draft starts closer to what you'd write yourself, and you spend your time sharpening it instead of filling a blank page.

<Steps>
  <Step title="Describe what you need">
    Say what the doc is for, who it's for, and what you already know. For example: "Write a PRD for the weigh and pay step of the pickup flow."

    <Tip>
      Tell Figr what's out of scope. A clear "not doing" list keeps the draft focused.
    </Tip>
  </Step>
  <Step title="Add supporting material">
    Click **Add context** in the chat box and attach research notes, customer feedback, screenshots of the current flow, or a page from a connected tool like Notion or Linear, so the doc builds on real inputs.

    <Frame>
      <img
        alt="Research files and a Notion page attached in the Figr chat box for a PRD"
        title="Add context for a PRD in Figr"
        src="/images/Screenshot-2026-10-21-at-3.27.28-PM.png"
      />
    </Frame>
  </Step>
  <Step title="Review the draft">
    Figr creates the doc on the canvas with sections like problem, goals, user stories and requirements.

    <Frame>
      <img
        alt="PRD draft with problem, goals, user stories and requirements on the Figr canvas"
        title="A PRD drafted by Figr"
        src="/images/Screenshot-2026-10-21-at-3.27.53-PM.png"
      />
    </Frame>
  </Step>
  <Step title="Refine it">
    Edit the doc directly, or ask Figr to expand a section, tighten the scope, or add open questions.
  </Step>
  <Step title="Ask Figr to map the flow">
    For example: "Map the user flow for this PRD, including what happens when something goes wrong."

    <Frame>
      <img
        alt="User flow mapped from a PRD, placed next to the doc on the Figr canvas"
        title="Map a user flow from a PRD"
        src="/images/Screenshot-2026-10-21-at-3.28.47-PM.png"
      />
    </Frame>
  </Step>
</Steps>
