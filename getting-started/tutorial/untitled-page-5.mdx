_Change your prototype yourself, or describe the change and let Figr make it._

<iframe src="https://www.youtube.com/embed/WvjteOi7cAo" title="Edit AI designs without regenerating the whole screen" frameBorder="0" className="w-full aspect-video rounded-xl" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen />

There are two ways to edit a prototype in Figr. Edit by hand for quick fixes you can see, like copy, colour and spacing. Edit with a prompt for changes to how the prototype works or how it's laid out, especially when they affect more than one screen.

## Edit by hand

<Steps>
  <Step title="Open the prototype in full screen">
    Double-click the prototype on your canvas to open full screen, then switch to the **Edit** tab.

    <Frame>
      <img
        alt="Interact, Edit and Comment tabs with Edit selected"
        src="/images/docs/edit-01-tab.png"
      />
    </Frame>
  </Step>
  <Step title="Click the element you want to change">
    Select any text, button, image or container on the screen. Its properties appear in the panel.

    <Frame>
      <img
        alt="Selected element with its properties panel open"
        src="/images/Screenshot-2026-10-21-at-3.40.06-PM.png"
      />
    </Frame>
  </Step>
  <Step title="Make your change">
    Type to update text, or change colour, size, spacing and alignment in the properties panel. When a design system is attached, pick its tokens instead of typing one-off values, so the change stays on-system.

    <Frame>
      <img
        alt="Properties panel with a design token being picked"
        src="/images/Screenshot-2026-10-21-at-3.40.39-PM.png"
      />
    </Frame>
  </Step>
  <Step title="Or prompt the selected element">
    Select a component and type the edit you want in the prompt box. It joins your other queued changes.

    <Frame>
      <img
        alt="Prompt typed for a selected component in Edit mode"
        src="/images/Screenshot-2026-10-21-at-3.41.56-PM.png"
      />
    </Frame>
  </Step>
  <Step title="Apply your changes">
    Edits queue up as you make them. Click **Apply changes** to apply them all at once. If you try to leave Edit mode with changes you haven't applied, Figr warns you first.
  </Step>
</Steps>

<Tip>
  Edit by hand for quick fixes like copy, colour and spacing. Ask Figr in chat when the change affects the whole screen or several screens at once.
</Tip>

## Edit with a prompt

Describe the change in chat and Figr makes it for you. Use prompts for:

- **New behaviour:** "When I click Delete, show a confirmation popup."
- **New screens or states:** "Add an empty state for when there are no projects yet."
- **Layout changes:** "Move the filters from the top bar into a left sidebar."
- **Changes across screens:** "Rename 'Workspace' to 'Team' everywhere."

<Frame>
  <img
    alt="A change described in chat and applied to the prototype"
    src="/images/Screenshot-2026-10-21-at-3.06.33-AM.png"
  />
</Frame>

When a change affects structure, like navigation or a layout pattern, Figr applies it everywhere it's used in the prototype, so every screen stays consistent.
