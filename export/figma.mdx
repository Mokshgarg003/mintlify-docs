_Send your Figr screens to Figma as editable frames._

The **Figr AI Figma Sync** plugin connects Figr and Figma. Set it up once, then export screens from Figr into Figma whenever you need to polish them or hand them off. You can also ask the Figr agent to keep editing a frame after it's in Figma.

## Set up the plugin

You only need to do this once.

<Steps>
  <Step title="Find the plugin in Figma">
    In Figma, open the Community and search for **Figr AI Figma Sync**.
  </Step>
  <Step title="Run it in a design file">
    Open any Figma design file, go to **Plugins**, and run **Figr AI Figma Sync**.
  </Step>
  <Step title="Sign in to Figr">
    Use the same account you use in Figr, so the plugin can see your projects.
  </Step>
</Steps>

## Export frames

<Steps>
  <Step title="Select the screens in Figr">
    Select a prototype on your canvas.
  </Step>
  <Step title="Send them to Figma">
    Open **Export** and choose **Export screens** to send one screen, or **Export all screens** to send the full flow.
  </Step>
  <Step title="Open them in Figma">
    Run the plugin in the Figma file where you want the screens. They arrive as editable frames with layers, text and auto layout.
  </Step>
</Steps>

## What comes across

| What | How it arrives in Figma |
| --- | --- |
| Layout | Frames with auto layout |
| Design values | Mapped to your Figma variables |
| Design system components | Instances of your Figma library components, where Figr can match them |
| Anything Figr can't match | A regular frame, with a note explaining why |

## Let the agent edit an exported frame

Your frame doesn't stop being editable by Figr once it's in Figma.

<Steps>
  <Step title="Select the frame in Figma">
    Select the frame and open the plugin.
  </Step>
  <Step title="Describe the change">
    For example: "Add an empty state to this list."
  </Step>
  <Step title="Review the update">
    The Figr agent edits the frame in place, keeping your design system styles.
  </Step>
</Steps>

<Tip>
  Export once your structure is settled. Small polish is quicker in Figma, but big layout changes are faster in Figr.
</Tip>

## Troubleshooting

| Issue | Fix |
| --- | --- |
| Figr can't find the plugin | Run Figr AI Figma Sync in your target file and check you're signed in |
| The plugin says Figma is in the background | Bring the Figma window to the front |
| One screen failed | Check the error shown for that screen, then export it again |
