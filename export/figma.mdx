_Send your Figr screens to Figma as editable frames._

<iframe src="https://www.youtube.com/embed/th-91Qr5q4Y" title="Figr screens: 25 Figma screens in one click" frameBorder="0" className="w-full aspect-video rounded-xl" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen />

The **Figr AI Figma Sync** plugin connects Figr and Figma. Connect it first, then export screens from Figr into Figma whenever you need to polish them or hand them off. You can also ask Figr to keep editing a frame after it's in Figma.

## Connect the plugin first

You only need to do this once.

<Steps>
  <Step title="Find the plugin in Figma">
    In Figma, open the Community and search for **Figr AI Figma Sync**.

    <Frame>
      <img
        alt="Figr AI Figma Sync in the Figma Community"
        src="/images/Screenshot-2026-10-21-at-3.57.25-PM.png"
      />
    </Frame>
  </Step>
  <Step title="Run it in the file where screens should land">
    Open the Figma design file, go to **Plugins**, and run **Figr AI Figma Sync**.

    <Frame>
      <img
        alt="Plugins menu with Figr AI Figma Sync"
        src="/images/Screenshot-2026-10-21-at-3.57.52-PM.png"
      />
    </Frame>
  </Step>
  <Step title="Sign in to Figr">
    Use the same account you use in Figr, so the plugin can see your projects. Keep the plugin open.
  </Step>
</Steps>

## Export screens

<Steps>
  <Step title="Select the prototype in Figr">
    Select a prototype on your canvas.
  </Step>
  <Step title="Send it to Figma">
    Open **Export**, then **Export to Figma**, and choose **Export this screen** or **Export all screens**.

    <Frame>
      <img
        alt="Export to Figma menu with Export this screen and Export all screens"
        src="/images/Screenshot-2026-10-21-at-3.58.26-PM.png"
      />
    </Frame>
  </Step>
  <Step title="Pick them up in Figma">
    The screens land in the file where the plugin is running, as editable frames with layers, text and auto layout.

    <Frame>
      <img
        alt="Exported frames in a Figma file"
        src="/images/Screenshot-2026-10-21-at-3.59.13-PM.png"
      />
    </Frame>
  </Step>
</Steps>

## What comes across

| What | How it arrives in Figma |
| --- | --- |
| Layout | Frames with auto layout |
| Design values | Mapped to your Figma variables |
| Design system components | Instances of your library components, when you export into the library file itself |
| Anything Figr can't match | A regular frame, with a note explaining why |

## Ask Figr to edit an exported frame

Your frame doesn't stop being editable by Figr once it's in Figma.

<Steps>
  <Step title="Select the frame in Figma">
    With the plugin connected, select the frame you want to change.

    <Frame>
      <img
        alt="A frame selected in Figma with the plugin open"
        src="/images/Screenshot-2026-10-21-at-3.59.44-PM.png"
      />
    </Frame>
  </Step>
  <Step title="Describe the change in Figr's chat">
    Back in Figr, type the change in the chat and name Figma. For example: "In Figma, add an empty state to this list."

    <Frame>
      <img
        alt="A change for the Figma frame typed in Figr's chat"
        src="/images/Screenshot-2026-10-21-at-4.00.24-PM.png"
      />
    </Frame>
  </Step>
  <Step title="Review the update in Figma">
    Figr edits the frame in place, keeping your design system styles.

    <Frame>
      <img
        alt="The updated frame in Figma"
        src="/images/Screenshot-2026-10-21-at-4.00.46-PM.png"
      />
    </Frame>
  </Step>
</Steps>

<Tip>
  Export once your structure is settled. Small polish is quicker in Figma, but big layout changes are faster in Figr.
</Tip>

## Troubleshooting

| Issue | Fix |
| --- | --- |
| Figr can't find the plugin | Run Figr AI Figma Sync in your target file and check you're signed in |
| The plugin says Figma is in the background | Bring the Figma window to the front |
| One screen failed | Check the error shown for that screen, then export it again |
| Components came across as frames | Export into the file that holds your component library |
