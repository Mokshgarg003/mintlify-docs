Select an item on the canvas and open **Export** to take its output out of Figr.

| Option | What you get | Use it for |
| --- | --- | --- |
| Copy code | The prototype's code, on your clipboard | Pasting into your project or a coding agent |
| Download PNG | An image of the design | Slack updates, decks, specs, reviews |
| Download PDF | A PDF of the design or doc | Sharing a doc or a fixed snapshot |
| Download Markdown | The text content as Markdown | PRDs and specs in your docs tool |
| Copy as text | The content as plain text | Pasting copy into a doc or ticket |

## The code

Prototypes are real front-end code in React or Angular, built with your design system's components when one is attached. To read the code before you copy it, open the prototype in **Full screen** and switch on **Code**.

To build with it in your own codebase, use **Open in coding agent** instead. Your agent reads the design, your components and the reasoning behind them through [Figr MCP](/export/mcp).

<Tip>
  Don't send a vague idea to engineering. Use Figr to settle the flow, states and design direction first, then hand off.
</Tip>
