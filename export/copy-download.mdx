Select an item on the canvas and open **Export** to take its output out of Figr. The options depend on the item type.

| Item | Option | Use it for |
| --- | --- | --- |
| Prototype | Download code | Handing off to developers, running it locally, or starting from it in your codebase |
| Prototype | Copy this screen | Pasting the current screen somewhere else |
| Flow diagram | Copy code | Pasting the flow into a doc or tool that reads its code |
| Flow diagram | Download PNG | Slack updates, decks, specs, reviews |
| Doc | Download PDF | Sharing a fixed snapshot |
| Doc | Download Markdown | PRDs and specs in your docs tool |
| Doc | Copy as text | Pasting the content into a doc or ticket |

## The code

Prototypes are real front-end code in React or Angular, built with your design system's components when one is attached. To read the code first, open the prototype in **Full screen** and switch on **Code**.

To build with it in your own codebase, use **Open in coding agent** instead. Your agent reads the design, your components and the reasoning behind them through [Figr MCP](/export/mcp).

<Tip>
  Don't send a vague idea to engineering. Use Figr to settle the flow, states and design direction first, then hand off.
</Tip>
