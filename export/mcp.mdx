Figr MCP gives coding agents the real design behind your screens: its code, structure, values, your design system and the reasoning that shaped it. MCP (Model Context Protocol) is an open standard that lets AI tools connect to outside sources. Your agent builds from the actual design instead of guessing from a screenshot.

## What your agent can do

<CardGroup cols={2}>
  <Card title="See what's in a project" color="#695BE8" icon="folder-open">
    List the designs, conversations and files in a project.
  </Card>

  <Card title="Read any design" color="#695BE8" icon="file-code">
    Open a design to see its code and how it was built.
  </Card>

  <Card title="Use your design system" color="#695BE8" icon="palette">
    Read your real components and tokens, and build against them.
  </Card>

  <Card title="Understand the why" color="#695BE8" icon="lightbulb">
    Pull the reasoning behind a design from your conversations with Figr.
  </Card>

  <Card title="Search across designs" color="#695BE8" icon="magnifying-glass">
    Find elements, patterns or text across a project.
  </Card>

  <Card title="Create and edit in Figr" color="#695BE8" icon="pen-to-square">
    Write access lets an agent add and change content in Figr. Changes show in the project chat and version history.
  </Card>
</CardGroup>

<Note>
  Write access is available to select organizations. [Talk to us](https://figr.design/contact) to turn it on.
</Note>

## Add Figr MCP to your editor

Register the server once so your agent can reach any project you have access to. The server URL is `https://mcp.figr.design/mcp`.

<Tabs>
  <Tab title="Claude Code">
    Install the Figr plugin from **Open in coding agent**, or add the server in your terminal:

    ```bash
    claude mcp add figr --transport http https://mcp.figr.design/mcp
    ```
  </Tab>
  <Tab title="Cursor">
    1. Open **Cursor → Settings → Cursor Settings**.
    2. Click **Tools & Integrations**.
    3. Under **MCP Tools**, click **\+** to add a custom MCP server.
    4. Paste this into `mcp.json` and save.

    ```json
    {
      "mcpServers": {
        "figr": {
          "type": "http",
          "url": "https://mcp.figr.design/mcp"
        }
      }
    }
    ```
  </Tab>
  <Tab title="Google Antigravity">
    1. Open the MCP store from the **...** menu at the top of the agent panel.
    2. Click **Manage MCP Servers**, then **View raw config**.
    3. Add Figr to `mcp_config.json`.

    ```json
    {
      "mcpServers": {
        "figr": {
          "command": "npx",
          "args": ["-y", "mcp-remote", "https://mcp.figr.design/mcp"],
          "env": {}
        }
      }
    }
    ```
  </Tab>
  <Tab title="Other agents">
    Any agent that supports HTTP (Streamable HTTP) transport can connect. Add the server manually:

    ```json
    {
      "mcpServers": {
        "figr": {
          "type": "http",
          "url": "https://mcp.figr.design/mcp"
        }
      }
    }
    ```
  </Tab>
</Tabs>

The first time your agent connects, you sign in to Figr and approve access.

## Access scopes

| Scope | What it allows |
| --- | --- |
| `figr:read` | Read projects, designs, design systems and conversations you can access |
| `figr:write` | Create and edit content in Figr (select organizations) |

Your agent can only reach what your Figr account can reach.

## Best practices

- Start from **Open in coding agent** on the design you're building. The starter prompt keeps the agent focused on that screen.
- Attach your design system in Figr before handing off, so the agent builds with your real components.
- Review the access you're approving before you sign in from a new agent.

## Troubleshooting

| Issue | Fix |
| --- | --- |
| Agent can't reach the server | Check the URL is exactly `https://mcp.figr.design/mcp` |
| Stuck on "Requires authentication" | Reconnect from your agent and finish the Figr sign-in |
| Agent can't see a design | Make sure your Figr account has access to that project |
| Agent can read but not write | Write access is limited to select organizations |
