Export is a handoff decision. Ask where the work goes next, then pick the path.

| Where it goes next | Use | Menu item |
| --- | --- | --- |
| A designer polishes it in Figma | [Export to Figma](/export/figma) | Export screens / Export all screens |
| Stakeholders or users review it | [Publish a prototype](/export/publish) | Publish |
| Your team keeps working on it | [Share a project](/export/share-project) | Share |
| An engineer builds it with an AI agent | [Figr MCP](/export/mcp) | Open in coding agent |
| An engineer wants the code | [Copy and download](/export/copy-download) | Copy code |
| A deck, doc or ticket | [Copy and download](/export/copy-download) | Download PNG / PDF / Markdown, Copy as text |
| Future work in Figr | [Context Pods](/product-intelligence/context-pods) | Add to Context Pod |

Open **Export** from the toolbar on any selected prototype, or from full screen. See [Item actions](/canvas/action-items) for the full toolbar.
