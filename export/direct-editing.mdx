Direct editing lets you change individual elements in a prototype without sending a new prompt for every edit.

## Open it

Select the prototype and click **Edit** in its toolbar, or open it in **Full screen** and switch to the **Edit** tab. Then click the element you want to change.

## What you can change

| Property | Examples |
| --- | --- |
| Text | Labels, headings, body copy |
| Colour | Text, background, border |
| Font | Family, weight, size, line height |
| Size | Width and height |
| Spacing | Padding and gaps |
| Borders and radius | Border width and corner radius |

Changes preview live. Make several, then apply them together. Figr warns you if you try to leave Edit mode with changes you haven't applied.

## Your design system stays connected

When a design system is attached, the panel offers its values, so you pick a colour or spacing token instead of creating a one-off style. Edits to a shared component apply everywhere that component appears.

## Prompt the selected element

When a change needs more context, type a prompt for the selected element instead. Figr changes only that element.

Use a chat prompt when the change affects several elements or needs Figr to reason through the UX.
