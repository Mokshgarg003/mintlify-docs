Direct Editing lets you change a design without describing every small edit in a prompt.

Select an element to see the values behind it, change them directly, or prompt that specific element when words are faster.

## See what is actually being used

When you select an element, Figr shows its properties, including:

- Font
- Colour
- Size
- Line height
- Spacing
- Position and alignment

You can quickly check whether a value comes from your design system or sits outside it.

If you choose an off-system value, Figr warns you instead of blocking the change.

## Make the change directly

Some edits are easier to make than explain.

Change copy, resize an element, adjust spacing, move it, or fix alignment directly on the canvas.

For example, changing **Client Orders** to **Orders** should not need another prompt.

## Your design system still applies

Direct Editing does not disconnect the design from your product context.

Figr applies your changes to the source with your design system and code context behind it. Existing tokens and components stay in use unless you deliberately choose another value.

## Prompt when it makes more sense

Direct Editing does not replace prompting.

Select an element and prompt it when the change needs more context or is easier to describe.

Use direct editing when you know the exact change. Use a prompt when you want Figr to think through the change with you.
